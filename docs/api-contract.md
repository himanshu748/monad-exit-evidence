# Current read-only API contract

All responses use `{data: VALUE|null, error: null|{code,message}, meta:{receivedAt}}`. The app serves actual provider observations or explicit errors/unavailable states.

- GET `/api/health`: `LIVE_READ_ONLY`, simulationEnabled false, tradingEnabled false; actual Envio status per network; Perpl public-read-configured; CRE omitted-user-choice; Nansen access-required.
- GET `/api/markets?network=mainnet|testnet`: real public Perpl context and precision, source URL/time, stale flag and human decimal market values.
- GET `/api/book?network=&marketId=`: actual public book levels, source timestamps/precision and context freshness. No quantity or estimate is assumed.
- GET `/api/liquidity?network=&marketId=&quantity=&direction=long|short`: quoted depth for a quantity explicitly supplied by the user. Long exit consumes bids; short consumes asks. This never submits an order or guarantees a fill.
- GET `/api/activity?network=`: fresh validated full normalized Envio events, chain ID, committed watermark and optional explicit window start. This is a preview of at most 50 events. Missing/stale sources yield unavailable, null watermark and no events. In optional HyperSync mode, engine/sourceUrl identify the provider, windowStartBlock and watermark delimit a fully scanned window of at most 16 recent blocks, and providerHead identifies its checked head. providerHeadObservedAt is that head block’s chain timestamp, not a request-completion time; receivedAt records the source-read start.
- GET `/api/observations?network=&transactionHash=&logIndex=`: independent public Monad receipt/canonical block and strict ABI decode. A transaction outside the preview is looked up by exact primary key in genuine indexed SQL, atomically with committed progress. Complete normalized event comparison yields INDEX_AND_CHAIN_MATCH, SOURCE_MISMATCH or CHAIN_OBSERVED. A missing HyperIndex record remains NOT_IN_CURRENT_PAGE. After a live, fully covered exact-block HyperSync lookup, absence of the independently observed event is MISSING_IN_INDEX with SOURCE_MISMATCH and a failed source comparison, not a window warning. Missing ABI fields remain null. Exact observation export includes source timestamps/checks/limitations and a change-detection digest.
- GET `/api/nansen/status`: access-required; never a live portfolio badge.
- Opt-in local GET `/api/indexer-snapshot?network=`: validated public SQL fields/progress for the deployment bridge; disabled by default and on Vercel. Optional transactionHash plus logIndex selects one genuine indexed entity; no SQL/database endpoint or runtime path is returned. ENVIO_BRIDGE_ONLY=1 restricts the tunnel server to this route.
- `/api/rehearsals` and `/api/receipts/verify`: HTTP 410 SIMULATION_REMOVED.
- All other API methods: 405 READ_ONLY. Public mode limits: 40 admitted reads/minute and four concurrent reads per IP group, plus 120/minute and six concurrent globally per instance. Observations are additionally bounded at one concurrent read per group and two per instance; exhausted capacity returns 429 READ_LIMIT with a retry hint. Observation-concurrency denials use a fixed backoff rather than predicting when existing work will finish. Denied calls do not spend another shared admission. No trading route or arbitrary upstream is accepted.

Inputs start empty. Switching networks clears quantities/transaction evidence; stale asynchronous reads cannot replace edited inputs. Exports contain the unchanged returned observation JSON. Public participant events establish neither viewer ownership nor an execution performed by this app.

Browser request deadlines: ordinary reads remain bounded at 35 seconds; independent observation reads allow 65 seconds to cover the server’s bounded provider work under its 60-second function limit plus transport time. Timers clear after success, failure or cancellation, with no automatic retries.

In optional HyperSync mode, an older receipt supplies only its block locator. The indexed-side event values come from a fully covered exact-block HyperSync query. Exported source metadata retain the engine, fixed source URL, provider head, head block timestamp and exact queried coverage.

The browser expires displayed evidence conservatively against its local clock; a skewed device clock can mark otherwise valid data stale. It does not invent fresh source times. Overview activity reads accept cancellation when the overview unmounts. Cancellation is distinct from the normal 35-second read deadline and does not claim to stop work already running on the server. Non-JSON provider/function responses produce an HTTP-status error rather than exposing parser internals.
