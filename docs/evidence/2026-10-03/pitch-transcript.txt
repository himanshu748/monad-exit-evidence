A trading request is not a fill, and a missing response is not success. Exit Evidence Workbench helps teams see those distinctions before trusting automation around a position reduction.
The actual product combines public Perpl liquidity on Monad with exact hypothetical limits, durable request identities, explicit partial and unknown outcomes, and inspectable receipts. Envio adds real public exchange activity through committed SQL watermarks. The screen you see is a recording of that local product.
Our first users are Monad trading-tool builders, protocol integration teams, and people testing automated exits. We will start with hands-on debugging sessions, publish a reproducible example after release approval, and use small integration workshops to find repeated failure cases. We will measure whether users can explain a partial or unknown result, recover the same request, and export evidence without assistance.
The current build is a read-only local prototype. It does not own a deployed onchain mechanism or execute trades. The next milestone is confirming track fit, reviewing any useful testnet evidence registry, and approving a hosted demo. Envio is the supported bounty candidate; CRE simulation and live Nansen access are not claimed. Our value is evidence that makes uncertainty understandable.
