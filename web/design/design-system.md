# Exit evidence visual system

Accepted direction: approved focused specification, generated full-screen concept in exit-evidence-concept.png. Desktop reference 1536 × 1024. Concept-only quantities are not production fixtures.

## Composition
- 208px dark navigation rail; 28px canvas gutter; compact single line title and subtitle.
- Left work column contains public liquidity then hypothetical limits. Right column contains scenario controls and receipt outcome. The activity section spans both.
- Surface color #FFFEFA, canvas #F6F4EF, rail #121A1F, ink #172027, muted #647078, border #DEDCD6, green #25604B, amber #8A6418, red #9A3C37.
- Flat 1px borders, 6px corners, no gradients and no shadows. Use border dividers within tables and lists.
- System sans typography; title 36/1.1, section headings 20/1.3, body 15/1.5, controls 15/1.2, quiet metadata 12/1.5. Tabular figures; mono only for exact integer strings and digests.
- Spacing scale 4, 8, 12, 16, 20, 24, 28, 32. Inputs/buttons at least 42px tall.
- Outline 20px rail icons, 1.7px rounded strokes; filled 8px semantic status dots. Status always has text.

## Components and interactions
- App shell; shared panel heading; genuine bid/ask tables; labeled native form controls; immutable reviewed-policy summary; scenario selector; amber/green/red outcome band; approved/observed comparison; check rows; receipt JSON inspector and verifier; activity status or actual events.
- All UI is semantic code-native HTML. No raster production assets required.
- At <1050px reduce rail to horizontal header. At <800px single column in liquidity, limits, outcome, activity order. No hidden fields or tables with clipped content.
- Keyboard-operable native selects and buttons; clearly visible focus. Reduced motion respected.

## Functional deviations from concept
The generated image is a visual reference, not a protocol design. Production must add the requested exact policy-binding review, all six scenarios, network/market/direction reset behavior, freshness/error states, replay execution control, inspection/export/import, and actual source timestamps. Copy varies only to reflect actual server facts. Concept data label and all pictured synthetic public-market rows must be absent in production. All hypothetical default inputs are explicitly hypothetical.
